# مرحله سوم ـ ورود و خروجی آفلاین JSON واژه‌نامه

## محدوده تغییر
این مرحله فقط قابلیت انتقال فایل JSON واژه‌نامه را به صفحه مدیریت واژه‌نامه در flavor مدیر اضافه می‌کند. هیچ صفحه، منطق یا فایل دیگری از قابلیت‌های برنامه عمداً تغییر داده نشده است.

## ورود
- فایل با قالب `tazieh-glossary` و `schemaVersion: 1` پذیرفته می‌شود.
- ورود افزایشی است؛ سرمدخل موجود بازنویسی نمی‌شود.
- سرمدخل با نرمال‌سازی مشترک فارسی تطبیق داده می‌شود.
- معنی‌های تکراری با متن و مشخصات منبع یکسان دوباره درج نمی‌شوند.
- صورت نوشتاری که با مدخل دیگری تعارض داشته باشد نادیده گرفته می‌شود.
- همه مدخل‌ها و معنی‌های واردشده با وضعیت `PENDING` ثبت می‌شوند تا مدیر آن‌ها را بررسی کند.
- SHA-256 فایل‌های واردشده در SharedPreferences مدیر ثبت می‌شود تا همان فایل دوباره اعمال نشود.
- سقف اندازه فایل ورودی ۱۰ مگابایت است.

## خروجی
- فقط سرمدخل‌های `VERIFIED` و معنی‌های `VERIFIED` در فایل قرار می‌گیرند.
- فایل شامل `format`، `schemaVersion`، `releaseId`، `generatedAt`، `terms` و `sha256` است.
- فایل از طریق انتخاب‌گر ذخیره‌سازی اندروید ذخیره می‌شود و برای انتقال آفلاین آماده است.

## محل آزمایش
Admin → مرکز فعالیت → دیکشنری اصطلاحات → «ورود و خروجی فایل واژه‌نامه»

## محدودیت اعتبارسنجی
ساختار ZIP و تغییرات متنی بررسی شده‌اند؛ Gradle/Android SDK در این محیط اجرا نشده و بیلد یا تست دستگاهی ادعا نمی‌شود. قبل از انتشار، هر چهار flavor و سناریوهای ورود فایل تکراری، فایل نامعتبر، تعارض املایی و خروجی فقط-تأییدشده باید در GitHub Actions و دستگاه آزمایش شوند.
